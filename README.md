# Yuvaraj's Portfolio

A personal portfolio website built with **React + TypeScript + Vite**, showcasing QA engineering experience, projects, and skills.

## 🚀 Tech Stack

- **React 19** + **TypeScript**
- **Vite** – build tool & dev server
- **Tailwind CSS v4** – styling
- **Framer Motion** – animations
- **Lucide React** – icons
- **EmailJS** – contact form

## 📁 Project Structure

```
src/
├── components/
│   ├── Home.tsx          # Hero section
│   ├── About.tsx         # About me + stats
│   ├── Experience.tsx    # Work timeline
│   ├── ProjectsSection.tsx  # Projects showcase
│   ├── SkillsSection.tsx # Skills grid
│   ├── Contact.tsx       # Contact form
│   └── ...               # UI components
├── hooks/                # Custom React hooks
└── assets/               # Images & media
```

## 🛠️ Getting Started

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
npm run preview
```
